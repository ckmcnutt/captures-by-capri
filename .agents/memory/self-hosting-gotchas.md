# Self-hosting gotchas

Non-obvious traps in the self-hosted stack, discovered while migrating off
Replit + Supabase. Each of these is silent — nothing fails loudly.

## CRON_SCHEDULE must fire at most once per day

The reminder windows in `services/scheduled-jobs.ts` (`d <= 3 && d > 2`,
`d <= 2 && d > 1`, `d <= 1 && d > 0`) are each a full 24-hour band, and no column
records that a reminder was already sent. An hourly schedule sends every reminder
up to 24 times — real Twilio spend, real annoyance for clients.

Finer resolution needs a schema change (a `last_reminder_sent_at` column), not a
config change.

`POST /api/jobs/run` is likewise not idempotent. When testing, leave
`TWILIO_*` and `SMTP_HOST` unset: both transports degrade to a
warn-and-skip.

## `appointment.id` is both a serial PK and a Cal.com bookingId sink

The Cal webhook inserts rows with an explicit id (the Cal `bookingId`), which
never advances the sequence. Two consequences:

- After any `--data-only` load the sequence sits at 1 while `max(id)` is large, so
  the next ordinary insert collides. `db/sql/110_sync_sequences.sql` is mandatory,
  not optional.
- `repositories/appointments.ts::insertAppointment` fast-forwards the sequence in
  the same transaction whenever an explicit id is supplied. Don't remove it.

The column must stay `serial` / `GENERATED BY DEFAULT`. `GENERATED ALWAYS` would
reject the explicit-id insert outright, and Drizzle doesn't emit
`OVERRIDING SYSTEM VALUE`.

## Image filename case: APFS lies to you

`media/home/` contains a mix of `hero.JPG`, `feature3.JPG` and `feature1.jpg`.
macOS APFS is case-insensitive, so a wrong-case reference works locally and 404s
on the LXC's ext4. Verified: `curl /media/home/hero.jpg` returns 200 on this Mac
even though the file is `hero.JPG`.

Run `bash scripts/db/check-media.sh` before deploying — it cross-checks
`photo.url` rows against files on disk and flags case-only mismatches.

## Express 5 throws on `app.get("*")`

Under path-to-regexp v8 a bare `"*"` route raises
`TypeError: Missing parameter name`. Every SPA-fallback snippet online is written
for Express 4. Use a terminal `app.use` instead.

Also: in `app.ts` the `/api` and `/media` 404 handlers MUST be registered before
the SPA fallback. Behind it they are unreachable, and unmatched paths answer 200
with `index.html` — which turns an API typo into a JSON parse error and a missing
photo into a blank `<img>` tile.

## Env-var booleans

`z.coerce.boolean()` is a trap: `Boolean("false") === true`, so `SERVE_STATIC=false`
would silently enable static serving. `src/env.ts` parses the literal words
instead.

## Relative directory paths

`MEDIA_DIR=./media` resolves against `process.cwd()`, which differs between
`pnpm --filter ... dev` (`artifacts/api-server`) and a systemd unit. `src/env.ts`
resolves relative paths against the repo root so both agree.
